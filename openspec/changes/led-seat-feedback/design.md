## Accepted scope
Implement core feedback and full LED parameters. No game engine, countdown, score, AI phase or theme system. CLI display requests never change audio configuration or ownership. RAM-only device settings; JSON layout retained on Mac.
## Rendering
12 LED positions at 30-degree intervals; zero angle and direction configurable. 1..8 unique regions, angle0..359, full arc width1..360; inclusive boundaries, nearest LED fallback (lowest index on tie), reject mask overlap. Priorities: fault, physical mute, timed identify/preview, raw manual, real events, real owner/receiving, existing idle effects. Blue intensity15 owner/30 receiving; grant double blink and amber denial double blink. Timers on device,100..60000ms. Expiry restores current state; disconnect cancels temporary effects. Sources unknown or spatial disabled never claim reception. Existing local state drives events; host stream/mute included in receiving eligibility.

## Execution
USB callbacks only mutate protected LED state; sole board task does I2C. Ring frames capped10Hz and unchanged frames skipped. Each active color write is read back. Request results distinguish received/applied/covered/failed/expired; applied means validated device configuration or verified I2C write, not visual observation. CLI waits3s for matching ID; supersession/timeout is an error. Last applied RGB readback is historical, not continuous hardware observation.
