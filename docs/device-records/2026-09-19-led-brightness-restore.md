# 静音切换后亮度恢复候选

实机诊断重复读回LED亮度127，应用要求30。现有代码只在last_led无效/初始化时设置亮度，正常静音和解除的效果转换不重写；且此前写入顺序是亮度在效果前。官方RGB示例按效果、颜色、速度、亮度的顺序设置：https://wiki.seeedstudio.com/respeaker_xvf3800_xiao_rgb/ 。官方示例没有声明“效果必定重置亮度”，不能把写入顺序直接当作内部行为证据。

本次修正：每次应用状态改变，先设置并读回效果、颜色、速度，最后设置并读回亮度30；稳定状态不重复写入、不增加逐帧灯效命令。白色呼吸及彩虹速度仍为1。物理静音逻辑、音频增益、AGC诊断、唤醒模型均保持现状。
