# 用户语音备忘录样本分析

输入为用户提供的17.065秒单声道48kHz AAC文件。使用macOS afconvert解码为16bit PCM，没有增强或归一化。原始语音文件不加入Git，记录文件哈希和幅度统计。

全段峰值-6.32dBFS，RMS-27.79dBFS，无满幅样本。第0–3秒各秒RMS约-55.57至-48.65dBFS，第5–8秒-42.15至-35.44dBFS，第12秒-17.64dBFS。各片段可能包含不同语音、停顿或碰撞，不能把这些差异直接归因于增益变化。等待用户确认距离/音量/设备移动情况。

可确认文件自身幅度随时间显著变化，不能笼统声称全程幅度均匀偏小。峰值距离数字满幅仅6.32dB，因此不先盲目提高固定倍数。语音备忘录输出48kHz不证明USB固件输入格式错误，应用可能重采样；AAC有损编码也不支持逐位判断I2S有效位或USB零填充。当前没有听辨/转写结论或信噪比结论。

官方命令表提供PP_AGC开关、目标电平、当前增益与时间常数；自动增益只是待验证候选原因，尚未读回这些参数，更未更改。来源：https://github.com/respeaker/reSpeaker_XVF3800_USB_4MIC_ARRAY/blob/a652fe79da3a292b25decc0e1e7f267d29bb0284/python_control/xvf_host.py

统计证据：logs/2026-09-18-recording-metrics.json。

## 第二份录音：用户标注静音后恢复

10.6227秒48kmono AAC，解码为s16后的峰值-41.43dBFS，RMS-67.41dBFS，无满幅削波。相对上一份峰值低35.11dB、全段RMS低39.62dB；两段语料/距离/说话响度未确认一致，差值不是可归因于设备静音的受控增益测量。每0.5秒统计多数落在-65至-87dBFS，没有持续恢复到第一份后半段幅度。存在极弱非零信号，不能将其认定为有清楚语音或正常拾音；有损AAC无法证明静音阶段PCM零填充或原始有效位。

这份样本证明记录数据本身非常弱，不能将用户体验归因于回放音量。结合用户描述，应重点验证静音解除前后信号链路/增益/抑制状态；当前证据不足以指定AGC、AEC或PCM格式为根因。未修改增益、路由或强制解除静音。

证据：logs/2026-09-18-mute-recording-metrics.json。录音提供后再读的现场HID另存logs/2026-09-18-after-muted-recording.json，仅代表读取时刻，不代表录音全过程。
