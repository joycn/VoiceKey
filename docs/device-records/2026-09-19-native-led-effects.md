# 白色呼吸与唤醒彩虹灯

用户最终选择官方内置灯效，取代尚未烧录的蓝色自定义旋转方案。正常就绪为白色呼吸，触发快捷键后彩虹保持5秒，再恢复白色；静音红色、故障紫色常亮优先。设备没有Mac对话生命周期回传，5秒是触发反馈窗口。短按B沿用相同反馈，启动时按住B不再误触发。

动画由XMOS运行，控制任务仅在状态变化时写入并读回：resource20 command12为effect，13为brightness32，15为speed1，16为color。首次初始化/故障恢复重设亮度速度。没有逐帧通信，没有AGC或静音解除写入。协议按XMOS镜像来源提交a652fe79da3a292b25decc0e1e7f267d29bb0284中的官方python_control/xvf_host.py核对。
