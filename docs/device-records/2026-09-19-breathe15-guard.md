# 呼吸15与参数回退保护

用户在速度20实测失败后指定白色15、彩虹3、亮度10。源码已采用此组合。白色15写入/读回失败时，尝试写入并验证此前稳定的5；仅在5验证成功后缓存回退选择，直到重启不再尝试15，避免同一无效参数造成连续配置失败。若回退也失败，仍保留原有控制失效关闭保护。控制错误计数保留失败尝试，不隐瞒故障。

原生适配器测试覆盖参数被裁剪导致读回不匹配、回退5成功且控制状态保持有效、后续切换不再重试15；其余runtime/audio/WakeNet适配器测试及OpenSpec校验通过。15的设备支持情况和实际灯效仍需烧录后验证；当前HID诊断不暴露实际LED速度，不能只凭运行身份宣称15已被采用。

设备当前仍可能运行速度20失败版，本版尚未烧录，需要进入ROM下载模式。

交叉编译与8MB镜像校验通过；应用413584字节，SHA256 `f4ef3577c0088052e1749c31ba5ac7bf2f7c80d11081ac16a1e8a95c07da7d86`。
