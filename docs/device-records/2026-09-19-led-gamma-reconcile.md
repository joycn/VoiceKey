# LED低亮度与参数覆盖候选

用户反馈白色呼吸和彩虹均不可见。只读确认供电开启、亮度30/速度1/Gamma1、控制错误0；另有早期读回效果5/亮度127/速度8的独立快照，说明目标设置有被覆盖现象，来源尚未证实。低亮度叠加Gamma导致不可见是待实机验证假设，不能用寄存器正确读回代替肉眼确认。

仅修改LED：每次配置显式写Gamma0，保持亮度30、速度1；读完一组有效效果/亮度/速度/Gamma后若不符合目标，在下一控制轮恢复。参数一致时不重写，避免反复重启动画。无效读回不触发配置推断；现有控制缓存保护继续生效。未改音频/静音/AGC，不增加软件静音实验入口。

测试运行实际board.c，模拟外部把效果/亮度/速度/Gamma同时改为5/127/8/1，最终恢复1/30/1/0，且只有一组五次写入，后续正常轮询不重启效果。适配测试全部通过；尚待交叉编译及烧录，视觉可见性仍待用户确认。
